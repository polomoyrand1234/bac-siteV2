Primitives usuelles

∫ x^n dx = x^(n+1)/(n+1) + C pour n ≠ -1 ∫ 1/x dx = ln x + C ∫ e^x dx = e^x + C ∫ e^u·u' dx = e^u + C ∫ u'/u dx = ln|u| + C ∫ cos x dx = sin x + C ∫ sin x dx = -cos x + C ∫ a dx = ax + C

Théorème fondamental

  • Si F est une primitive de f sur [a,b], alors ∫[a,b] f(x) dx = F(b)-F(a).
  • Notation à bien écrire : [F(x)]_a^b = F(b)-F(a).

Interprétation

  • L’intégrale représente une aire algébrique.
  • Aire entre une courbe positive et l’axe des abscisses : A = ∫[a,b] f(x) dx.

Méthodes

  • Chercher une primitive adaptée.
  • Penser à reconnaître u'/u ou e^u·u'.
  • Pour l’aire, vérifier le signe de la fonction sur l’intervalle.

Lien avec dérivation

  • Si F(x)=∫[a,x] f(t)dt, alors F'(x)=f(x) sous les hypothèses du cours.

Primitives usuelles propres

∫ x^n dx = x^(n+1)/(n+1) + C si n ≠ -1 ∫ 1/x dx = ln|x| + C ∫ e^x dx = e^x + C ∫ cos(x) dx = sin(x) + C ∫ sin(x) dx = -cos(x) + C ∫ u′/u dx = ln|u| + C
Intégrale définie : ∫[a→b] f(x) dx = F(b) - F(a) = [F(x)]_a^b

Sens et usages

  • L’intégrale peut représenter une aire algébrique : les zones sous l’axe des abscisses comptent négativement.
  • Pour une aire géométrique totale, on découpe l’intervalle si la fonction change de signe.
  • Une primitive n’est jamais unique : on ajoute une constante réelle C.

Calculer une intégrale

Trouver une primitive adaptée, puis appliquer F(b)-F(a) proprement, avec les crochets.

Aire

Si la fonction est positive sur l’intervalle, l’intégrale correspond à l’aire sous la courbe.

Piège classique

Bien distinguer primitive et intégrale définie : l’une est une fonction, l’autre un nombre.
