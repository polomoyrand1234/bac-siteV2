Type 1 : y' = ay

  • Solution générale : y(x)=Ce^(ax).
  • Avec condition initiale y(x0)=y0, on détermine C.

Type 2 : y' = ay + b

  • Chercher d’abord une solution particulière constante y_p = -b/a si a≠0.
  • Solution générale : y(x)=Ce^(ax)+y_p.

Type 3 : y' = ay + f(x)

  • Au lycée, on traite surtout le cas où on sait deviner une solution particulière adaptée à f.
  • La solution générale = solution de l’homogène + solution particulière.

Méthode

  • 1. Identifier le type d’équation.
  • 2. Écrire la solution générale.
  • 3. Utiliser la condition initiale.
  • 4. Vérifier par dérivation.

À ne pas oublier

  • Toujours donner l’intervalle si nécessaire.
  • Soigner la distinction solution générale / particulière.

Méthodes selon le type d’équation

  • Type y′ = ay : solution générale y(x)=Ce^(ax).
  • Type y′ = ay + b : on cherche d’abord une solution constante puis on ajoute la solution de l’équation homogène.
  • Avec condition initiale y(x₀)=y₀, on remplace pour déterminer la constante C.
  • Toujours vérifier la solution obtenue en la remplaçant dans l’équation différentielle.

Ce qu’on attend souvent

  • Déterminer la solution générale, puis la solution particulière vérifiant une condition donnée.
  • Reconnaître un modèle d’évolution exponentielle ou une stabilisation autour d’une valeur limite.
  • Interpréter graphiquement la solution dans un contexte de population, refroidissement ou charge/décharge simplifiée.

Compléments bac — méthode de résolution

y' = ay → y = Ce^{ax} y' = ay + b → solution constante y0 = -b/a puis y = y0 + Ce^{ax}
  • Pour vérifier une solution, on dérive puis on remplace dans l'équation.
  • Pour déterminer la constante C, on utilise la condition initiale donnée dans l'énoncé.
  • Le chapitre relie souvent équation différentielle et modélisation d'une grandeur physique ou économique.

Formulaire bac complet — équations différentielles

y'=ay ⇒ y(x)=Ce^(ax)
y'=ay+b ⇒ y(x)=Ce^(ax)-b/a si a≠0
Solution particulière constante de y'=ay+b : y_p=-b/a
Condition initiale y(x_0)=y_0 : utiliser pour déterminer C

Méthode type

1. Résoudre l’équation homogène. 2. Chercher une solution particulière. 3. Additionner. 4. Utiliser la condition initiale.

Vérification

Toujours re-remplacer la solution obtenue dans l’équation différentielle pour vérifier.

Piège classique

Ne pas oublier que la constante C change d’un exercice à l’autre et doit être déterminée à la fin.
