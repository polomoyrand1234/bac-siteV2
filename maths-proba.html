Probabilités, variables aléatoires, loi binomiale

Rappels

  • P(Ā)=1-P(A)
  • P(A∪B)=P(A)+P(B)-P(A∩B)
  • P_B(A)=P(A∩B)/P(B) si P(B)≠0.

Indépendance

  • A et B sont indépendants si P(A∩B)=P(A)P(B).
  • Alors aussi P_B(A)=P(A).
  • Attention : incompatibles ≠ indépendants, sauf cas trivial.

Formule des probabilités totales / Bayes

  • Si les B_i forment une partition : P(A)=Σ P(B_i)P_{B_i}(A).
  • Bayes : P_A(B)=P(B)P_B(A)/P(A).

Loi binomiale

  • X suit B(n,p) si X compte le nombre de succès dans n épreuves de Bernoulli indépendantes de même probabilité p.
  • Rédaction type : “Chaque épreuve a deux issues, succès / échec ; elles sont indépendantes et la probabilité du succès est constante p. Donc X suit une loi binomiale B(n,p).”

Formules binomiales

Si X ~ B(n,p) : P(X=k)=C(n,k) p^k (1-p)^(n-k) E(X)=np V(X)=np(1-p) σ(X)=√(np(1-p))

Probabilités : rédaction attendue

  • Pour dire que X suit une loi binomiale B(n,p), il faut écrire : on répète n épreuves de Bernoulli indépendantes et identiques, chacune de probabilité de succès p ; X compte le nombre de succès.
  • Deux événements A et B sont indépendants si P(A∩B)=P(A)P(B).
  • En arbre pondéré, vérifier que la somme des probabilités issues d’un même nœud vaut 1.
  • En loi binomiale : P(X=k)=C(n,k) p^k (1-p)^(n-k), E(X)=np, V(X)=np(1-p), σ(X)=√(np(1-p)).

Réflexes bac

  • Traduire soigneusement la situation avant tout calcul : variable aléatoire, événement, indépendance, répétition.
  • Vérifier si l’ordre compte ou non : c’est souvent la clé pour choisir le bon modèle.
  • Justifier l’usage de la loi binomiale avant de calculer les probabilités.

Compléments bac — indépendance et loi binomiale

Indépendance : P(A∩B)=P(A)P(B) Variable binomiale X~B(n,p) : P(X=k)=C(n,k)p^k(1-p)^(n-k) Espérance : E(X)=np ; Variance : V(X)=np(1-p)
  • Rédaction-type : « On répète n fois, de façon indépendante, une expérience de Bernoulli dont le succès a pour probabilité p ; donc X suit la loi binomiale B(n,p). »
  • Ne pas confondre indépendance et incompatibilité.
  • Pour une variable binomiale, la somme des probabilités peut être demandée sous forme P(X≥k) ou P(X≤k).

Formulaire bac complet — probabilités, variables aléatoires, binomiale

P(A∪B)=P(A)+P(B)-P(A∩B) ; P_A(B)=P(A∩B)/P(A)
Si les B_i forment une partition : P(A)=Σ P(B_i)P_{B_i}(A)
Bayes : P_A(B)=P(B)P_B(A)/P(A)
E(X)=Σ x_i p_i ; V(X)=E(X²)-E(X)² = Σ p_i (x_i-E(X))² ; σ(X)=√V(X)
E(aX+b)=aE(X)+b ; V(aX+b)=a²V(X) ; σ(aX+b)=|a|σ(X)
Si X et Y indépendantes : V(X+Y)=V(X)+V(Y)
Bernoulli : E(X)=p ; V(X)=p(1-p) ; σ(X)=√(p(1-p))
Binomiale B(n,p) : P(X=k)=C(n,k)p^k(1-p)^(n-k) ; E(X)=np ; V(X)=np(1-p) ; σ(X)=√(np(1-p))
Échantillon : S_n=X_1+...+X_n ⇒ E(S_n)=nE(X), V(S_n)=nV(X), σ(S_n)=√n σ(X)
M_n=S_n/n ⇒ E(M_n)=E(X), V(M_n)=V(X)/n, σ(M_n)=σ(X)/√n
Markov : P(X≥a)≤E(X)/a ; Bienaymé-Tchebychev : P(|X-E(X)|≥a)≤V(X)/a²

Montrer que X suit une loi binomiale

Écrire : on répète n épreuves de Bernoulli identiques et indépendantes, chacune de probabilité de succès p ; X compte le nombre de succès. Donc X suit B(n,p).

Indépendance

Ne pas confondre indépendance et incompatibilité. Le bon critère est P(A∩B)=P(A)P(B).

Réflexe arbre

Sur chaque embranchement, les probabilités issues d’un même nœud doivent sommer à 1.
