Définitions

  • Une suite est une fonction définie sur N.
  • On peut la définir explicitement, par récurrence ou via un algorithme.
  • Chercher le sens de variation, la borne, la limite.

Suites arithmétiques

u_(n+1)=u_n+r u_n = u_0 + nr ou u_n = u_1 + (n-1)r Somme : u_0 + u_1 + ... + u_n = (n+1)(u_0+u_n)/2 De u_1 à u_n : u_1 + ... + u_n = n(u_1+u_n)/2

Suites géométriques

u_(n+1)=q u_n u_n = u_0 q^n ou u_n = u_1 q^(n-1) Somme : u_0 + ... + u_n = u_0 (1-q^(n+1))/(1-q) si q ≠ 1 De u_1 à u_n : u_1 + ... + u_n = u_1 (1-q^n)/(1-q) si q ≠ 1

Raisonnement par récurrence

  • Initialisation : vérifier au rang de départ.
  • Hérédité : supposer la propriété vraie au rang n puis la démontrer au rang n+1.
  • Conclusion : la propriété est vraie pour tout n à partir du rang initial.

Limites classiques

  • Si q vérifie |q|<1, alors q^n → 0.
  • Si q>1, alors q^n → +∞.
  • Pour une suite définie par u_(n+1)=a u_n+b, on cherche souvent le point fixe ℓ tel que ℓ=aℓ+b.

Réflexes sur les suites

  • Identifier d’abord le type : suite explicite, récurrente, arithmétique, géométrique ou définie par une fonction.
  • Pour une suite récurrente uₙ₊₁ = f(uₙ), penser au sens de variation de f et aux points fixes.
  • Pour montrer qu’une suite converge, utiliser selon le cas : monotonie + bornes, gendarmes, convergence d’une géométrique, ou étude de f sur un intervalle stable.
  • Ne pas confondre majorée/minorée et croissante/décroissante : ce sont deux idées différentes.

Sommes à connaître

Somme arithmétique : 1 + 2 + ... + n = n(n+1)/2 Plus généralement : S = nombre de termes × (premier + dernier) / 2
Somme géométrique : 1 + q + q² + ... + q^n = (1-q^(n+1)) / (1-q) si q ≠ 1

Compléments bac — sommes et raisonnements

Somme arithmétique : u0+u1+...+un = (n+1)(u0+un)/2 Somme géométrique : 1+q+q²+...+q^n = (1-q^(n+1))/(1-q) si q ≠ 1
  • Pour montrer qu'une suite est monotone, compare u_{n+1}-u_n ou u_{n+1}/u_n selon la forme.
  • Pour une suite définie par récurrence, pense à chercher un intervalle stable puis à étudier la fonction associée.
  • Les théorèmes de convergence les plus utiles au bac sont : suite monotone et bornée, théorème des gendarmes, limite d'une suite géométrique.

Récurrence

Initialisation, hérédité, conclusion : toujours annoncer clairement la propriété au rang n et au rang n+1.

Montrer qu’une suite est géométrique

Vérifier que le quotient u_(n+1)/u_n est constant sur les indices où il est défini.

Montrer qu’une suite est arithmétique

Vérifier que la différence u_(n+1)-u_n est constante.
