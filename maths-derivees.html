Dérivation, variations, tangentes, dérivée seconde

Définitions essentielles

  • La dérivée f'(a) mesure le taux de variation instantané de f au point a.
  • f est dérivable sur un intervalle si elle admet une dérivée en tout point de cet intervalle.
  • Le signe de f' donne le sens de variation de f.
  • La dérivée seconde f'' sert à étudier la convexité.

Formules usuelles

(u+v)' = u' + v' (uv)' = u'v + uv' (u/v)' = (u'v - uv') / v² (u∘v)' = u'(v(x)) × v'(x) (x^n)' = n x^(n-1) (1/x)' = -1/x² (1/u)' = -u'/u² (e^x)' = e^x (e^u)' = u'e^u (ln x)' = 1/x (ln u)' = u'/u (cos x)' = -sin x (sin x)' = cos x (cos u)' = -u' sin(u) (sin u)' = u' cos(u)

Méthode complète

  • 1. Calculer f' proprement.
  • 2. Étudier le signe de f' sur le domaine.
  • 3. Faire le tableau de variations.
  • 4. Si demandé, calculer f''.
  • 5. Étudier le signe de f'' pour la convexité / concavité.
  • 6. Pour la tangente en a : y = f'(a)(x-a) + f(a).

À savoir sur la dérivée seconde

  • Si f'' > 0 sur un intervalle, f est convexe.
  • Si f'' < 0 sur un intervalle, f est concave.
  • Si f'' change de signe en a, on a un point d’inflexion.
  • Lien graphique : sur une courbe convexe, les tangentes sont en dessous de la courbe ; sur une courbe concave, elles sont au-dessus.

Croissances comparées

  • Quand x → +∞, les puissances sont négligeables devant l’exponentielle.
  • Quand x → +∞, le logarithme est négligeable devant les puissances.
  • Exemple : ln(x) << x^a << e^x pour tout a > 0.

Automatismes à maîtriser

  • Savoir dériver sans hésiter une somme, un produit, un quotient et une composée.
  • Passer de f′ au tableau de variations puis, si besoin, de f′′ au tableau de convexité.
  • Reconnaître immédiatement l’équation de la tangente en a : y = f′(a)(x-a) + f(a).
  • Ne pas oublier le domaine de définition avant de dériver, surtout avec ln(u), 1/u ou √u.

Ce qu’on peut te demander au bac

  • Étudier complètement une fonction : domaine, limites, dérivée, variations, convexité, tangente.
  • Justifier qu’une fonction est croissante sur un intervalle en étudiant le signe de f′.
  • Montrer qu’une courbe admet un point d’inflexion en repérant un changement de signe de f′′.
  • Utiliser les croissances comparées pour lever une forme indéterminée dans une limite.

Compléments bac — dérivées, convexité, lecture graphique

Dérivée seconde : f'' permet d'étudier la convexité f'' > 0 → courbe convexe f'' < 0 → courbe concave f'' change de signe → point d'inflexion Tangente en a : y = f'(a)(x-a)+f(a)
  • Quand une étude de fonction devient longue, pense à séparer : domaine, limites, dérivée, tableau de variations, puis convexité.
  • Si la dérivée s'annule en changeant de signe, on conclut sur un extremum local.

  • Pour une composition, on peut demander seulement la dérivée, mais aussi le sens de variation si le signe de u' et le comportement de la fonction extérieure sont connus.

1. Calculer f'. 2. Chercher son signe. 3. Faire le tableau de variations. 4. Conclure avec une phrase complète.

Étudier la convexité

1. Calculer f''. 2. Étudier le signe de f''. 3. Dire où la fonction est convexe ou concave. 4. Repérer un éventuel point d’inflexion.
