Limites usuelles

x→+∞ : 1/x → 0 1/x² → 0 ln x → +∞ x^a → +∞ si a>0 e^x → +∞ e^(-x) → 0 x→0 : sin x / x → 1 (1-cos x)/x → 0 ln(1+x)/x → 1 e^x - 1 over x → 1 x→+∞ : ln x / x → 0 x^a / e^x → 0 (a réel)

Continuité

  • Une fonction est continue en a si lim f(x) = f(a) quand x tend vers a.
  • Les fonctions polynômes, rationnelles (sur leur domaine), exponentielle, logarithme, trigonométriques sont continues sur leur domaine.
  • Si une fonction est continue et strictement monotone sur un intervalle, elle réalise une bijection sur son image.

Fonction logarithme

  • ln(ab)=ln a + ln b
  • ln(a/b)=ln a - ln b
  • ln(a^n)=n ln a
  • e^(ln x)=x pour x>0
  • ln(e^x)=x
  • Dérivée : (ln x)'=1/x sur ]0,+∞[.
  • Primitive : ∫(1/x)dx = ln x + C sur ]0,+∞[.

TI et lecture graphique

  • Le taux d’accroissement entre a et b est (f(b)-f(a))/(b-a).
  • La dérivée est la limite du taux d’accroissement quand b tend vers a.
  • Sur calculatrice, distinguer valeur approchée, tableau, courbe, et estimation numérique d’une limite.

Méthodes

  • Factoriser en cas de formes indéterminées.
  • Multiplier par l’expression conjuguée si une racine gêne.
  • Comparer les croissances (ln, puissances, exp).
  • Utiliser la continuité pour passer à la limite.

Limites usuelles à connaître

Quand x → +∞ : ln(x)/x → 0 1/x → 0 1/x^n → 0 e^x/x^n → +∞ Quand x → 0 : ln(x) → -∞ sur x>0 1/x → ±∞ selon le signe Limites classiques : ln(1)=0 e^0=1

Continuité et logarithme : attentes

  • Le théorème des valeurs intermédiaires sert à garantir l’existence d’une solution d’équation f(x)=k sur un intervalle où f est continue.
  • Le logarithme népérien est défini sur ]0,+∞[ uniquement : c’est le premier réflexe à rappeler dans une étude.
  • À connaître : ln(ab)=ln(a)+ln(b), ln(a/b)=ln(a)-ln(b), ln(a^n)=nln(a).
  • Pour les asymptotes, distinguer verticale (limite infinie en un point) et horizontale/oblique (limite à l’infini).

Compléments bac — limites usuelles à connaître absolument

  • Le théorème des valeurs intermédiaires sert à justifier l'existence d'une solution ; il faut citer continuité et encadrement de la valeur cherchée.

  • Pour les limites avec ln, rappelle toujours le domaine : x>0.

Formulaire bac complet — limites, continuité, logarithme

lim[x→+∞] 1/x=0 ; lim[x→+∞] x^n=+∞ ; lim[x→+∞] e^x=+∞ ; lim[x→-∞] e^x=0
lim[x→0+] ln x=-∞ ; lim[x→+∞] ln x=+∞
lim[x→0] sin x/x=1 ; lim[x→0] (e^x-1)/x=1 ; lim[x→0] ln(1+x)/x=1
Croissances comparées : ln x << x^a << e^x en +∞ (a>0)
ln(ab)=ln a+ln b ; ln(a/b)=ln a-ln b ; ln(a^n)=n ln a ; e^(ln x)=x ; ln(e^x)=x
TVI : si f est continue sur [a,b], alors toute valeur entre f(a) et f(b) est prise

Résoudre f(x)=k

Montrer que f est continue puis strictement monotone sur l’intervalle étudié ; utiliser le TVI puis l’unicité.

Asymptotes

Verticale si f(x)→±∞ près d’un réel a ; horizontale si f(x)→ℓ en ±∞ ; oblique si f(x)-(ax+b)→0.

Réflexe avec ln

Toujours préciser le domaine : ln(u(x)) n’a de sens que si u(x)>0.
