Repères majeurs

  • Fait / droit : ce qui est / ce qui doit être.
  • Moyen / fin : instrument / but.
  • Objectif / subjectif : indépendant du point de vue / dépend de la perception.
  • Absolu / relatif : vaut par soi / dépend d’un cadre.
  • Nature / culture : donné / acquis.
  • Essentiel / accidentel : ce qui définit / ce qui peut varier sans détruire l’être.
  • Légal / légitime : conforme à la loi / moralement juste.
  • Conscient / inconscient : connu de soi / agissant sans être su.
