Fiche réorganisée avec rappels de formules, méthodes et points d’attention.

← Retour aux chapitresVoir les ECE

Radioactivité

  • N(t)=N0 e^(-λt)
  • t_1/2 = ln2 / λ
  • A = λN.

Nombre d’entités

  • n = N/NA avec NA constante d’Avogadro.
  • N = n NA.

Photon / effet photoélectrique

  • E = hν = hc/λ
  • Plus la fréquence ν est grande, plus l’énergie du photon est grande.

Gaz parfait

  • pV = nRT
  • Température en kelvins.

Fluides

  • Poussée d’Archimède : Π = ρ_fluide V_immergé g
  • Direction verticale, sens vers le haut.

Formules à ajouter

Radioactivité : N(t)=N₀e^{-λt} Activité : A=λN Demi-vie : t₁/₂ = ln(2)/λ
Nombre d’entités : N = nN_A Énergie du photon : E = hν Effet photoélectrique : hν = W_e + E_c,max
Gaz parfait : PV = nRT Poussée d’Archimède : Π_A = ρVg

Fluides et gaz : repères

  • Débit volumique : D_v = V/Δt = vS pour un écoulement uniforme.
  • Pour un gaz parfait, convertir la température en kelvins.
  • Pour une poussée d’Archimède, le volume à considérer est le volume immergé.

Radioactivité

Bien distinguer nombre de noyaux N, activité A et demi-vie t_{1/2}.

Photon

Ne pas oublier que ν=c/λ si l’énoncé donne une longueur d’onde.

Gaz / fluides

Identifier la bonne modélisation : gaz parfait, débit, continuité ou poussée d’Archimède.
